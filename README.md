# 结构之间 · 数据结构交互实验室

用可以修改输入、逐步前进与回退的实验，理解从线性表到图的数据结构。

**在线使用：** https://bydtesla1609.github.io/data-structure-lab/

## 内容与功能

- **24 个知识主题、72 个操作实验、172 项操作说明、24 道自测题。**
- 输入数据即时计算演示轨迹；支持播放/暂停、单步前进/后退、任意步骤定位、0.5～3 倍速。
- 同步展示结构、变量、伪代码和文字推导。13 个典型例题直接绑定实验参数，另有 24 个原创延伸例题。
- 知识速查包含基本定义、存储表示、复杂度的成立条件和易错点。
- 可搜索章节，学习进度保存在当前浏览器；支持手机布局、键盘操作和减少动态效果偏好。

| 教材范围 | 主题 |
| --- | --- |
| 第2章 线性表 | 顺序表、单链表、双链表、循环链表、静态链表 |
| 第3章 栈、队列和数组 | 顺序/链栈、共享栈、循环/链队列、双端队列、栈与队列应用、数组与特殊/稀疏矩阵 |
| 第4章 串 | 存储和基本操作、朴素匹配、KMP、π/next/nextval |
| 第5章 树与二叉树 | 性质和存储、遍历与重建、线索二叉树、树与森林、哈夫曼树、并查集 |
| 第6章 图 | 概念与四种存储表示、基本操作、BFS/DFS、Prim/Kruskal、Dijkstra/Floyd、DAG、拓扑排序、关键路径 |

完整对应表见 [COVERAGE.md](COVERAGE.md)。并非每一种实现的每项操作都有独立动画；全部主题的典型操作与前提均在知识速查中列出。第7章查找和第8章排序不在本次“线性表到图”的范围内。

## 本地运行

本项目是零运行依赖的静态网站，无需 `npm install`，使用现代浏览器即可。

```sh
# 安装 Node.js 22 或更新版本后
npm start
# 浏览器打开 http://127.0.0.1:4173
```

也可以使用任意静态 HTTP 服务。由于通过 `fetch` 读取章节 JSON，不应直接双击 HTML 使用 `file://` 打开。

```sh
npm test
```

测试覆盖全部实验默认输入、空结构/满结构/非法输入、矩阵压缩下标、穷举小字母表字符串匹配、独立枚举验证最小生成树、最短路、负权环、拓扑环检测以及多源汇 AOE 网。浏览器验收记录见 [VALIDATION.md](VALIDATION.md)。

## 使用约定

- **位序与下标分开标注。** 链表/插删表单使用 1 起始位序，数组槽位为 0 起始下标。
- 矩阵动画使用 1 起始行列、0 起始压缩数组下标；知识速查也给出明确声明的 0 起始公式，两者勿混用。
- KMP 使用 0 起始的前缀长度表 π；另一个实验展示与教材 1 起始 next、nextval 的对应关系。
- 图的邻居按字母升序处理，平权边按端点顺序打破平局。并不意味着遍历序列或最优解一定唯一。
- 循环队列演示使用“牺牲一个单元”的约定；其他判满方案见知识速查。
- 演示会保存每个状态以便回放，**快照成本不属于原算法的辅助空间复杂度**。
- 为保证图形可读性，输入有明确上限（如图最多8顶点、数组最多16项）。这些是演示限制，不是数据结构本身的限制。

## 文件说明

- `index.html`、`styles.css`、`app.js`：界面与统一播放器。
- `algorithms.js`：无 DOM 依赖的确定性算法轨迹生成器。
- `content-*.json`：原创章节讲解、操作表、自测与例题。
- `tests.mjs`：可重复的独立结果和边界校验。
- `server.mjs`：本地静态预览服务。

## 教材与内容来源

以用户提供的《2025 王道数据结构考研复习指导》第2—6章为范围，完整读取该扫描件 PDF 第26—290页的 OCR，并查看关键公式和图示原页核对。网站给出节号、书页和该扫描件的 PDF 页码；该文件的书页通常等于 PDF 页码减14。OCR不是逐字可靠的校勘，涉及公式、算法前提和例题结果另行计算校验。

本项目是独立制作的学习辅助工具，与教材出版方无关联。教材文字、扫描图、PDF、OCR全文均不包含在仓库；知识表述和练习讲解重新组织，动画与示例数据为原创。

部署为 GitHub Pages 静态站点，无账号系统、后台服务或第三方统计；浏览器进度仅使用 `localStorage`。
